# 개발 계획 — 프로젝트 단절 (Project: SEVERANCE)

---

## Step 0. 프로젝트 기반 세팅
- [x] Unity 6 2D 프로젝트 확인, 기본 폴더 구조 정리 (Core/, Grid/, Emitter/, Turn/, Input/, UI/)
- [x] 커스텀 Grid 시스템 선택 (GridManager + TileData 순수 C#)
- [x] `GameManager` 싱글톤 생성 (Singleton<T> 베이스)
- [x] `GridManager` 싱글톤 생성

---

## Step 1. 그리드 & 타일 시스템
> 모든 메카닉의 기반. 가장 먼저 완성해야 함.

- [x] `TileData` 순수 C# 클래스 — Position, Owner, Level, ResourceType, ParentEmitters
- [x] `GridManager` — 2D 배열, GetTile, IsInBounds, GetNeighbors, GetTilesInRadius
- [x] `TileView` — 소유자·레벨별 색상 그라데이션, 디버그 텍스트, FoW 오버레이
- [x] `GridVisualizer` — 타일 프리팹 인스턴스화, 중심 정렬
- [x] 카메라 세팅 — 2D 탑다운 뷰, 드래그/줌 이동

**검증:** Play 모드에서 NxM 그리드가 렌더링되고, 특정 타일 클릭 시 Inspector에서 데이터 확인.

---

## Step 2. 턴(틱) 시스템
- [x] `TurnManager` 싱글톤 — 코루틴 기반 6-phase 턴 루프, 수동/자동 모드
- [x] 턴 순서: AllyExpansion → EnemyExpansion → CollisionResolution → DependencyCheck → ResourceUpdate
- [x] `TurnUI` — 턴 카운터, Next Turn 버튼, Auto-Play 토글

**검증:** 버튼 클릭 시 턴 카운트 증가, 콘솔에 각 페이즈 로그 출력.

---

## Step 3. 진원(Emitter) — 배치 & 기본 확장
- [x] `Emitter` 순수 C# 클래스 — Owner, Level, Direction, IsOn, ExpansionFrontier
- [x] `EmitterManager` — TryPlaceEmitter (레벨/소유권 검증), ExpandAll (방향별 프론티어)
- [x] 확장 로직 — ON 상태일 때 턴마다 방향 템플릿에 따라 1칸씩 영역 생성
- [x] `InputHandler` — Select 모드 (토글), PlaceEmitter 모드 (배치)

**검증:** 진원 배치 후 턴 진행 → 지정 방향으로 타일이 1칸씩 플레이어 색으로 변함.

---

## Step 4. 영역 충돌 & 교착 (Stalemate / Push)
- [x] 동일 레벨 충돌 → 교착 판정 (양측 모두 해당 타일 진입 불가)
- [x] 한쪽 OFF/전력 부족 시 → 반대편이 덮어쓰기(Push)
- [x] 상위 레벨 → 하위 레벨 무조건 덮어쓰기

**검증:** 양측 Lv1 영역을 마주치게 배치 → 교착 확인. 한쪽 OFF → Push 확인.

---

## Step 5. 교집합 레벨링 (Stacking System)
- [x] 같은 소유자의 동일 레벨 영역 2개가 같은 타일에서 교차 → 해당 타일 레벨 +1 승격
- [x] 승격된 타일 위에서만 해당 레벨 진원 설치 허용
- [x] 최대 레벨 상한 설정 (예: Lv5)

**검증:** Lv1 진원 2개를 교차 배치 → 교차 지점 Lv2 확인 → Lv2 진원 설치 가능 확인.

---

## Step 6. 종속성 & 연쇄 붕괴 (Cascading Failure)
- [x] 각 영역 타일이 부모 진원까지의 경로(BFS/DFS) 유지
- [x] 타일 덮어쓰기 발생 시 → 끊어진 타일 탐색 → 연결 끊긴 영역 소멸
- [x] 소멸로 교집합 깨짐 → 상위 진원 파괴 → 해당 진원이 뿜던 상위 영역들까지 연쇄적으로 셧다운
- [x] 시각 연출: 붕괴 시 순차적 타일 소멸 애니메이션 (코루틴)

**검증:** 적 Lv2 구역의 하위 연결부를 끊었을 때 상위 영역까지 연쇄 소멸 확인.

---

## Step 7. 자원 시스템 (Power & Veins)
- [x] `ResourceManager` — 전력(Power), 광맥(Veins) 보유량 관리
- [x] 전력 노드 타일 — 영역 편입 시 매 턴 전력 +N
- [x] 광맥 노드 타일 — 영역 편입 시 일정 턴마다 획득, 종류별(철/구리/규소) 방향 템플릿 차등
- [x] 전력 부족 → 모든 확장 일시정지
- [x] UI: 전력·광맥 현황 표시

**검증:** 전력 노드 편입 → 턴마다 전력 증가. 전력 0 → 확장 정지 확인.

---

## Step 8. 전장의 안개 (Fog of War)
- [x] 전체 맵 Black mask로 시작
- [x] 아군 영역 타일 기준 반경 2칸 시야 공개
- [x] 영역 상실 시 시야 즉시 회수 (재 마스킹)
- [x] 렌더링: 타일맵 위에 FoW 레이어 또는 타일별 alpha 제어

**검증:** 진원 확장에 따라 안개가 걷히고, 영역 붕괴 시 다시 덮이는지 확인.

- [x] 적 확장 패턴: 사방 무지성 확장 or 플레이어 코어 방향 최단거리 확장
